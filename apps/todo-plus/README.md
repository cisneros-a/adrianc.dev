# To Do +

A to-do list with priorities, deadlines and task types, served at **https://todo-plus.adrianc.dev**.

The repo-wide requirements and decisions in the root [CLAUDE.md](../../CLAUDE.md) apply here. This file covers what's specific to this app.

## Status

**Iteration 1 (in progress):** front end only, with tasks saved in the browser's localStorage. Built: add tasks, list with default order, filters by status/priority/type/deadline, detail panel with autosave, mark done, delete, and a System/Light/Dark theme toggle.

**Iteration 2 (planned):** full stack with a real database and sign-in.

## Code layout

| Path                                  | What it does                                                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `src/lib/tasks/model.ts`              | The task shape and the fixed lists (priorities, types, statuses)                                              |
| `src/lib/tasks/storage.ts`            | The only code that reads/writes saved tasks (TD5); replaced in iteration 2                                    |
| `src/lib/tasks/store.ts`              | In-memory task list, `useTasks()`, and add/update/delete                                                      |
| `src/lib/tasks/filters.ts`            | Filtering by status, priority, type and deadline (T2), and default order (TD15)                               |
| `src/lib/tasks/dates.ts`              | Deadline helpers ("Today", "Overdue") in the user's local time                                                |
| `src/lib/theme.ts`, `theme-script.ts` | Light/dark choice and the `<head>` script that applies it (TD12)                                              |
| `src/components/`                     | UI: `TodoApp` (the screen), `QuickAdd`, `FilterBar`, `TaskItem`, `TaskPanel`, `ThemeToggle`, and small pieces |
| `src/app/globals.css`                 | Theme color tokens for light and dark (TD13)                                                                  |

## Commands

Run from the repo root:

```bash
pnpm --filter todo-plus dev        # dev server at http://localhost:3001
pnpm --filter todo-plus build      # static export to out/
pnpm --filter todo-plus preview    # build, then serve out/ with wrangler dev (http://localhost:8788)
pnpm --filter todo-plus lint
pnpm --filter todo-plus typecheck
pnpm --filter todo-plus deploy     # build, then wrangler deploy (see the Deployment section in CLAUDE.md)
```
