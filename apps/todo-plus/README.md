# To Do +

A to-do list with priorities, deadlines and custom categories, served at **https://todo-plus.adrianc.dev**.

The repo-wide requirements and decisions in the root [CLAUDE.md](../../CLAUDE.md) apply here. This file covers what's specific to this app.

## Status

**Iteration 1 (in progress):** front end only, with tasks saved in the browser's localStorage. Built: search, add tasks (with a + toggle for adding several in a row), list grouped into Overdue / Today / Tomorrow / Other (collapsible), filters by status/priority/type/deadline, task details modal with Save, subtasks, mark done (with a collapsible Completed section and undo), delete, templates (saved from the add panel or a task's details), subtasks when adding a task, and a Settings modal with the System/Light/Dark theme switch, defaults for new tasks, custom categories (add, edit, reorder, delete) and template editing.

**Iteration 2 (planned):** a real database and sign-in. Signed-out visitors keep using the app with localStorage as a demo; signing in syncs to the database. Its design is still to be agreed.

| `src/lib/tasks/dates.ts`                               | Deadline helpers ("Today", "Overdue") in the user's local time                                                                                                                                                   |

| `src/lib/categories/`                                  | Category palette (TD90) and icons (TD91), the category shape and seed, the only code that reads/writes saved categories (TD89), and the store with add/update/move/delete                                        |

## Commands

Run from the repo root:

```bash
pnpm --filter todo-plus dev        # dev server at http://localhost:3001
pnpm --filter todo-plus build      # static export to out/
pnpm --filter todo-plus preview    # build, then serve out/ with wrangler dev (http://localhost:8788)
pnpm --filter todo-plus lint
pnpm --filter todo-plus typecheck
pnpm --filter todo-plus run deploy # build, then wrangler deploy (see the Deployment section in CLAUDE.md)
```
